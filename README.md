# Music-Website-SecoStarr

A modern, responsive music streaming web application built with **React**, **Vite**, **Tailwind CSS**, and powered by the free **Audius Open API**.

## Features
- 🎵 **Full Track Streaming:** Play full-length tracks without 30-second cutoffs.
- 🔥 **Trending Charts & Genres:** Browse trending songs across Electronic, Hip-Hop, Pop, Rock, Lo-Fi, and more.
- 🔍 **Live Search:** Search songs, artists, and albums.
- ⏯️ **Modern Player Bar:** Play/Pause, Seek scrubber, Previous/Next queue, Shuffle, Repeat, and Volume controls.
- 🌙 **Spotify-like Dark UI:** Built with sleek Tailwind CSS and Lucide icons.

## Tech Stack
- React 19
- Vite
- Tailwind CSS v4
- Lucide React
- Audius API
